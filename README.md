# Hotel Booking Website

A simple hotel booking web app built using HTML, CSS, and JavaScript.

## Features

- Browse available hotel rooms
- Booking form with user details
- Date selection for check-in and check-out
- Responsive design

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository
2. Open `index.html` in any web browser

## Project Structure

- `index.html` – page structure
- `style.css` – styling
- `script.js` – booking logic and interactivity
